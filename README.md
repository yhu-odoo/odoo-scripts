# odoo-scripts

English | [中文](README.zh-CN.md)

Helper scripts for Odoo development.

| Script | Purpose |
|---|---|
| `configure_voip.py <db>` | Write the VoIP server settings and credentials (constants at the top of the file) into a database |
| `process_emojis.py` | Build per-language emoji JSON files (shortcodes, categories) from CLDR annotations |
